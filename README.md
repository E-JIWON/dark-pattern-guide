# 다크패턴 가이드라인 정리

공정거래위원회가 2026년 10월 6일 배포한 **「다크패턴 방지를 위한 온라인 인터페이스 운영 가이드라인」**을 기획자·개발자·디자이너가 읽기 쉽게 정리했습니다.

**👉 웹에서 보기: https://e-jiwon.github.io/dark-pattern-guide/**

- 13개 유형별로 문제 사례와 권장 방법을 나란히 정리
- 공정위 원문에 실린 예시 화면 29장
- 우리 서비스 점검표 (체크 후 마크다운으로 복사)
- 프로젝트에 바로 복사해 쓰는 [`CHECKLIST.md`](CHECKLIST.md)

> 개인이 만든 **비공식 요약**이며 법률 자문이 아닙니다. 실제 위반 여부는 법령, 「전자상거래 등에서의 소비자보호지침」, 공정위 판단이 우선합니다.

## 3줄 요약

1. **구독료 인상·무료→유료 전환**은 적용일 전 30일 안에 가입과 따로 **명시적 동의**를 받아야 하고, 동의하지 않으면 결제되면 안 됩니다.
2. **가격은 첫 화면부터 총금액**(배송비·세금 포함)으로 보여줘야 합니다.
3. **탈퇴·해지는 가입만큼 쉬워야** 합니다. 버튼은 로그인 첫 화면이나 마이페이지에, 가입한 채널(웹·앱)에서 바로 해지되게 만들어야 합니다.

## 13개 유형

| 범주 | 유형 | 한 줄 설명 | 근거 |
| --- | --- | --- | --- |
| 편취형 | 숨은갱신 | 가격 인상·유료 전환을 별도 동의 없이 자동결제 | 전자상거래법 §13⑥ |
| | 순차공개 가격책정 | 첫 화면엔 싸게, 결제 단계에서 필수 비용 추가 | §21조의2①1 |
| 오도형 | 특정옵션 사전선택 | 추가상품·부가서비스를 미리 체크 | §21조의2①2 |
| | 잘못된 계층구조 | 한 버튼만 크게, 다른 선택지는 흐리게 | §21조의2①3 |
| | 거짓 할인 | 판매된 적 없는 기준가로 할인율 과장 | §21①1, 표시광고법 §3① |
| | 거짓 추천 | 불리한 후기 삭제·숨김, 거짓 후기 작성 | §21①1, 표시광고법 §3① |
| | 유인 판매 | 안 파는 미끼상품으로 유인 | §21①1, 표시광고법 §3① |
| | 위장 광고 | 광고를 후기·기사처럼 위장 (뒷광고) | §21①1, 표시광고법 §3① |
| | 속임수 질문 | 이중부정, 두 가지를 한 번에 묻기 | §21①1 |
| 방해형 | 취소·탈퇴 등의 방해 | 해지 절차를 가입보다 복잡하게, 전화로만 해지 | §21조의2①4 |
| | 숨겨진 정보 | 할인 조건·제한 사항 은폐 | §13②, §21①1 |
| | 가격비교 방해 | 단위·중량을 빼서 비교를 어렵게 | §21①1 |
| 압박형 | 반복간섭 | 거절한 걸 팝업으로 계속 다시 묻기 | §21조의2①5 |

위반 시: 시정명령, 영업정지(1년 이내) 또는 과징금, 과태료 1천만~2천만 원 이하.
