출처: 공정위 보도참고자료 및 별첨 가이드라인(2026. 9., 소비자정책국 소비자거래정책과). 관련 기사 보기. 원문을 기획·개발 관점에서 읽기 쉽게 요약했습니다. 예시 화면은 가이드라인 별첨에 실린 공정위 예시 이미지이며, 누르면 크게 볼 수 있어요.

법적 구속력은 없음. 다만 전자상거래법·시행령·「전자상거래 소비자보호지침」의 해석과 공정위 모니터링·시정 사례를 묶어 놓은 문서라, 사실상 단속 기준으로 보면 됩니다. 2023년 자율관리 가이드라인과 2025년 6개 유형 문답서를 통합·현행화한 버전입니다.

핵심 요약

  • 4개 범주, 13개 유형으로 정리. 유형마다 개념 → 핵심 준수사항 → 세부 유의사항 → 위반·모범 예시 → Q&A 구성.
  • 정기결제 가격 인상·무료→유료 전환은 적용일 전 30일 안에 별도의 명시적 동의. "거부 안 하면 동의 간주"는 위반.
  • 가격은 첫 화면(검색결과·목록·배너)부터 총금액. 배송비·세금·현장결제 리조트피까지 포함.
  • 탈퇴·해지 버튼은 로그인 첫 화면이나 한 번 클릭으로 가는 화면(마이페이지 등)에 둘 것을 권고. '보안설정' 안에 숨기면 안 됨.
  • 가입한 방법 그대로 해지. 앱으로 가입받고 해지는 전화·챗봇만 되는 구조는 금지.
  • 거절한 걸 다시 묻는 팝업은 7일 이상 "다시 보지 않기" 옵션이 있어야 함.
  • 위반 시 시정명령, 영업정지(최대 1년) 또는 과징금, 과태료 최대 1천만~2천만 원.

다크패턴이란? 4개 범주 · 13개 유형

다크패턴(Dark Pattern)은 웹사이트나 앱 화면에서 소비자의 착각·부주의를 교묘하게 유발해 비합리적인 소비를 유도하는 행위입니다. 자동결제 몰래 갱신, 결제 단계에서 늘어나는 가격, 찾기 어려운 탈퇴 버튼, 거절해도 계속 뜨는 팝업이 대표적입니다. 공정위는 이를 작동 방식에 따라 4개 범주, 13개 유형으로 나눴습니다.

편취형

1.1 숨은갱신

전자상거래법 §13⑥과태료 ≤1천만 원

정기결제 금액이 오르거나 무료에서 유료로 바뀔 때, 따로 동의를 받지 않고 갱신·자동결제하는 행위.

핵심: 증액·전환일 전 30일 이내에 명시적 동의를 받고, 해지 조건·방법·효과를 고지. 동의 없으면 결제가 안 되게 설계.

공정위 원문 예시 화면

출처: 공정거래위원회 「다크패턴 방지를 위한 온라인 인터페이스 운영 가이드라인」 별첨 1.1 숨은갱신 예시 (2026. 10. 6. 보도자료)

문제 사례
  • "기간 내 거부하지 않으면 동의로 간주" 이메일만 보내고 자동 인상 결제
  • 신규 할인·무료 프로모션 약관에 "종료 후 정가 자동결제"만 넣고 별도 동의 없음
  • 프로모션이 30일 이내라 가입일이 동의 기간에 걸쳐도, 가입과 동시에 일괄 동의 받기
  • "예, 확인하였습니다" 버튼만 강조하고 거부 선택지 없음
이렇게
  • 팝업·푸시·이메일로 일시, 변경 전후 가격, 결제수단 고지 후 동의 받기
  • 미동의자는 인상 결제 없이 해지 또는 연장 중단
  • "아니오, 동의하지 않습니다" 같은 명시적 거부 항목 제공, 중립적 문구
Q&A 3개

100회 이용권 소진 시 다음 이용권 자동결제도 동의가 필요한가?

사용량 기반 결제는 독립된 재구매라 정기결제에 해당하지 않음. 다만 재결제 사항을 명확히 고지하는 것이 권장됨.

기존 구독자에게 준 일시 할인이 끝나 원래 가격으로 돌아가는 경우는?

이미 원래 가격을 내던 소비자이므로 대금 증액으로 보지 않음.

가격을 일괄 인상하고 개인별 갱신일에 적용하면 증액일은 언제?

개별 소비자에게 인상 가격이 적용되는 날(각자의 갱신일) 기준.

1.2 순차공개 가격책정

전자상거래법 §21조의2①1과태료 ≤1천만 원

첫 화면엔 싸게 보여주고, 구매가 진행될수록 필수 추가금을 하나씩 공개해 최종가를 청구하는 행위. 실제 구매로 이어지지 않은 단순 표시·광고만으로도 해당할 수 있음.

핵심: '첫 화면'은 가격을 처음 보는 모든 화면(검색결과, 카테고리 목록, 메인, 배너). 여기서부터 총금액(지불을 거부할 수 없는 모든 비용) 표시.

공정위 원문 예시 화면

출처: 공정거래위원회 「다크패턴 방지를 위한 온라인 인터페이스 운영 가이드라인」 별첨 1.2 순차공개 가격책정 예시 (2026. 10. 6. 보도자료)

문제 사례
  • 숙박 검색결과엔 세금 제외가, 결제 시 세금 포함 청구. 현장결제 리조트피는 아예 미표시
  • 배송비 있는 상품인데 검색결과에 배송비 언급 없음 (조건부 무료배송도 해당 가능)
  • 첫 화면에 가죽 소파 사진 + 패브릭 소파 가격 (§21① 기만행위 소지)
이렇게
  • 세금·필수 서비스료·현장결제 도시세까지 포함한 총금액을 검색결과에 표시
  • 고정 배송·설치비는 첫 화면에 표시, 변동이면 "배송비 별도" 표시
  • 공간이 부족하면 첫 화면엔 제외 항목만, 사유는 팝업·상세화면(스크롤 없이 보이게)
총금액에 넣는 것 / 안 넣어도 되는 것 · Q&A

포함 대상

배송비, 설치비, 부가세 등 제세공과금, 해외직구 관세, 여행 봉사료·청소비·도시세·숙박세, 착불 배송비·조립비 등 현장결제 비용.

제외 가능

소비자가 고른 특급배송비, 도서산간 추가배송비. 소비자 선택에 따라 달라져 일률 책정이 어려운 비용(정당한 사유, 첫 화면에 제외 항목·사유 고지 필요).

멤버십·제휴카드 조건부 할인가만 첫 화면에 표시하면?

순차공개는 아니지만 기만 우려가 있으므로, 누구나 받는 가격을 기준으로 하거나 조건을 가격 옆에 명시할 것을 권고.

오도형

2.1 특정옵션의 사전선택

전자상거래법 §21조의2①2과태료 ≤1천만 원

구매·가입 진행 중 다른 상품·서비스 청약 여부를 묻는 항목을 미리 '예'로 체크해 두는 행위.

핵심: 추가 구매·가입 항목은 비워두거나 '안 함'을 기본값으로. 뒤에 확인 단계·결제 단계가 있어도 위반 가능.

공정위 원문 예시 화면

출처: 공정거래위원회 「다크패턴 방지를 위한 온라인 인터페이스 운영 가이드라인」 별첨 2.1 특정옵션의 사전선택 예시 (2026. 10. 6. 보도자료)

문제 사례
  • 키오스크·앱에서 치즈버거를 누르면 '단품' 대신 더 비싼 '세트'가 기본 선택
이렇게
  • 추가상품 옵션은 미선택 또는 '구매 안 함' 기본
  • 옵션이 많으면 상품창을 분리해 초기부터 선택하게
적용 범위

해당 안 되는 경우

구매·가입 과정이 아닌 메인 화면 팝업의 개인정보·광고수신 동의, 이전 배송지·결제수단 같은 편의 목적 기본값. 단, 시각적으로 하나만 고를 수 있게 보이면 '잘못된 계층구조'가 될 수 있음.

2.2 잘못된 계층구조

전자상거래법 §21조의2①3과태료 ≤1천만 원

구매·가입·해지 선택지 사이에 크기·모양·색 차이를 현저하게 둬서, 하나만 고를 수 있거나 반드시 골라야 하는 것처럼 오인시키는 행위.

핵심: 강조 자체는 가능. 다른 선택지가 안 보이거나 없는 것처럼 느껴질 정도면 위반. 흐린 채도·명도, 작은 글자·작은 터치영역, 찾기 어려운 위치 모두 문제.

공정위 원문 예시 화면

출처: 공정거래위원회 「다크패턴 방지를 위한 온라인 인터페이스 운영 가이드라인」 별첨 2.2 잘못된 계층구조 예시 (2026. 10. 6. 보도자료)

문제 사례
  • 해지 화면에서 '이용권 변경'은 크고 컬러, '자동결제 해지'는 무채색 작은 글씨
  • 가격 변경 동의 팝업에 '동의'와 '7일간 보지 않기'만 있고 거부 항목 없음
이렇게
  • 대체 선택지와 해지 버튼을 비슷한 크기·색으로
  • 동의와 거부 항목을 함께, 시각적으로 비슷하게
적용 범위

해당 안 되는 경우

구매·가입·해지와 무관한 단순 광고·정보 제공 화면.

2.3 거짓 할인

전자상거래법 §21①1 · 표시광고법 §3①과태료 ≤2천만 원

기준가를 부풀리거나 할인율을 과장해 싸 보이게 하는 행위. 제조사 정가·권장가라고 기준가로 당연히 인정되지는 않음.

공정위 원문 예시 화면

출처: 공정거래위원회 「다크패턴 방지를 위한 온라인 인터페이스 운영 가이드라인」 별첨 2.3 거짓 할인 예시 (2026. 10. 6. 보도자료)

문제 사례
  • 행사 기간에 판매된 적 없는 가격으로 기준가를 올려 할인율 과장
  • '모바일 특가' 코너인데 웹 가격과 동일
  • 시술별 20~50% 할인인데 "50% 할인"으로 단정 표시
이렇게
  • 실거래 가격을 기준가로, 근거(종전 거래가, 공식판매가, 시가) 설명
  • 할인율은 사실대로, 범위면 범위로

2.4 거짓 추천

전자상거래법 §21①1 · 표시광고법 §3①과태료 ≤2천만 원

불리한 후기를 이유 없이 지우거나 숨기고, 유리한 후기를 거짓으로 만드는 행위. 정렬 조작으로 불리한 후기를 밀어내는 것도 포함.

문제 사례
  • 최신순·평점순 정렬처럼 보이지만 실제론 긍정 후기만 노출
  • 빈 상자 발송으로 구매 이력을 만들어 거짓 후기 작성
  • 직원 동원 배달 후기 작성, 주문수 부풀리기 (의뢰받은 대행사도 책임)
이렇게
  • 후기를 있는 그대로 노출, 노출 기준을 안내
  • 대가 제공 후기는 그 사실을 명확히 고지
  • 정보통신망법상 명예훼손 등 임시조치는 예외

2.5 유인 판매

전자상거래법 §21①1 · 표시광고법 §3①과태료 ≤2천만 원

실제로 안 파는 '미끼상품'을 판매 중인 것처럼 광고해 유인하는 행위. 순간 품절 자체는 바로 위반이 아니지만 재고는 주기적으로 반영해야 함 (대법원 2010두24371: 5일간 품절 상품 광고 방치 위반 인정).

문제 사례
  • 재고 없어 수개월 뒤 배송인데 판매 광고, 오픈마켓은 삭제 요구 무시
  • 70만 원 운동화를 최저가 대표노출 악용해 "35만 원 1개 남음" 허위 표시
  • "A브랜드 7,900원" 배너 → 클릭하면 21,800원 상품만 있음
이렇게
  • 실시간 재고 반영 시스템, 품절은 사실대로 표시
  • 실제 판매 상품만 광고

2.6 위장 광고

전자상거래법 §21①1 · 표시광고법 §3①과태료 ≤2천만 원

광고를 후기·기사·연구결과 등 광고가 아닌 콘텐츠처럼 위장하는 행위. 현금, 무상 제공, 수익 공유, 미래·조건부 대가 모두 '경제적 이해관계'.

문제 사례
  • 인플루언서에게 현금·제품 제공하고 광고 표시 없는 후기 게시 (뒷광고)
이렇게
  • '광고', '협찬' 등 한글 문구로 쉽게 찾고 알아볼 수 있게 표시
  • 상세 기준: 「추천·보증 심사지침 안내서」(’25.12.2.)

2.7 속임수 질문

전자상거래법 §21①1과태료 ≤2천만 원

의도하지 않은 답을 하게 하거나 아주 주의해서 봐야만 뜻을 알 수 있게 묻는 행위.

핵심: 한 질문 = 한 가지 뜻. 이중부정 금지. 두 가지 이상이면 질문과 선택지를 따로. 편의용 전체동의 버튼은 괜찮지만 개별 동의도 가능해야 함.

공정위 원문 예시 화면

출처: 공정거래위원회 「다크패턴 방지를 위한 온라인 인터페이스 운영 가이드라인」 별첨 2.7 속임수 질문 예시 (2026. 10. 6. 보도자료)

문제 사례
  • 구매 버튼 자리에 "프리미엄 멤버십 업그레이드 동의" / "업그레이드 하지 않음"을 둬서 업그레이드해야 구매되는 것처럼 보이게
  • "마케팅 메시지를 받고 싶지 않습니다 [X]" → X를 누르면 수신 동의
이렇게
  • 쉬운 단어, 긍정문
  • 구매와 멤버십 업그레이드는 별도 질문

3.1 취소·탈퇴 등의 방해

전자상거래법 §21조의2①4과태료 ≤1천만 원

가입·구매보다 취소·탈퇴·해지를 복잡하게 만들거나, 다른 방법으로만 하게 제한하는 행위. 보도자료에서 따로 짚은 유형입니다.

핵심: 가입한 방법 그대로, 간단하게. 복잡성은 클릭·메뉴·버튼 수(정량)와 진입 경로 찾기 난이도(정성)를 종합 판단.

3.2 숨겨진 정보

전자상거래법 §13② · §21①1과태료 ≤2천만 원

구매 결정에 필요한 중요 정보(가격, 수량, 수수료, 배송료, 공급 시기, 할인 조건·제한)를 숨기거나 빼거나 작게 보여주는 행위.

문제 사례
  • 멤버십 할인은 최초 1회뿐인데 비회원에게 모든 상품에 할인가 표시
  • "한 번 결제로 평생 무제한"인데 실제론 일부 기능만 무제한
  • 연 3회 할인인데 매월 할인되는 것처럼 표시
이렇게
  • 조건·제한을 일반 소비자가 인식할 수 있게 고지
  • 착오하기 쉬운 사항은 강조 표시

3.3 가격비교 방해

전자상거래법 §21①1과태료 ≤2천만 원

같은 종류 상품끼리 크기·수량·묶음 단위를 달리 표시해 비교를 어렵게 하는 행위.

문제 사례
  • 삼겹살을 '1팩'으로만 표시, 중량·단위가격 없음
  • 롤휴지 롤 수, 롤 길이, 1m당 가격 미표시
이렇게
  • 단위가격 표시, 일관된 비교 기준
  • 조건부 가격(특정 카드 등)은 조건을 명확히
  • 지역별·품목별 배송·설치비는 따로 알기 쉽게

압박형

4.1 반복간섭

전자상거래법 §21조의2①5 · 시행령 §27조의2과태료 ≤1천만 원

이미 내린 선택을 바꾸라고 팝업 등으로 2회 이상 요구하는 행위. 구매·가입에 한정되지 않고 광고수신·개인정보 동의 재요구가 대표 사례. 화면을 가려 선택하지 않으면 이용이 어려운 수준이어야 하며, 단순 배너는 해당 안 됨.

핵심: 번복 유도 팝업엔 "7일간 다시 보지 않기" 등 최소 7일 거부 옵션. 선택하면 그 기간 안엔 다시 묻지 않기.

공정위 원문 예시 화면

출처: 공정거래위원회 「다크패턴 방지를 위한 온라인 인터페이스 운영 가이드라인」 별첨 4.1 반복간섭 예시 (2026. 10. 6. 보도자료)

문제 사례
  • 멤버십 탈퇴 의사를 밝혔는데 별도 화면으로 새 멤버십 체험 계속 권유 (취소·탈퇴 방해와 중복 해당 가능)
  • 가격 인상 거부 다음날 접속하자 동의 팝업 재노출
이렇게
  • "7일간 다시 보지 않기" 제공, 선택 시 7일간 권유 중단
  • 거절한 사용자에겐 팝업 대신 배너로 변경 가능 안내
Q&A 3개

'닫기'나 '나중에 알림'을 누른 사람에게 다시 묻는 건?

선택을 미룬 것이므로 괜찮음. 단, 동의 항목만 있고 거부 항목이 없었다면 닫기를 실질적 거부로 보아 반복간섭이 될 수 있음.

'7일간 보지 않기'를 안 넣었다면 영원히 다시 못 묻나?

처음부터 넣는 게 바람직하지만, 없었다면 거부 후 7일이 지나면 다시 물을 수 있음.

'7일간 보지 않기'가 있으면 거부 버튼도 따로 필요한가?

법 문언상 없어도 됨. 다만 거부 버튼을 따로 두고, 거부 시 7일보다 더 길게 묻지 않는 것이 바람직.
